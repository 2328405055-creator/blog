# Ozon卖家账号注册全流程与常见驳回原因

Ozon跨境店注册已经相对成熟，但仍有不少卖家在注册阶段遇到问题。

## 准备资料清单

- 公司营业执照（中国大陆或香港公司）
- 法人身份证正反面
- 跨境电商平台经验证明（可选但加分）
- 对公账户或法人个人账户信息
- 联系电话和邮箱

## 注册流程

1. 访问 Ozon Seller 官网，选择"中国卖家"入口
2. 填写公司信息（中英文）
3. 上传营业执照和法人身份证
4. 填写店铺基本信息（店铺名称、主营类目）
5. 提交审核（通常3-7个工作日）
6. 审核通过后激活账号，签署电子合同
7. 完成收款账号绑定

## 常见驳回原因

| 驳回原因 | 解决方法 |
|---------|---------|
| 营业执照模糊 | 重新拍照或扫描，确保四角完整 |
| 法人信息不一致 | 确认营业执照和身份证信息一致 |
| 类目选择不合理 | 参考主营经验选择合适的类目 |
| 联系信息无效 | 确保电话和邮箱真实可用 |
| 已有重复账号 | 同一公司只能开一个跨境店 |

## 注册通过后的关键设置

- 设置仓库地址和发货方式
- 绑定收款账户（连连/PingPong等）
- 完成品牌备案（如有）
- 设置物流模板和退换货政策

> 注册不求快，求稳。一次通过比反复修改更省时间。
