# 跨境库存管理避坑指南：如何避免断货和冗余的双重困境

库存管理是跨境电商最容易被忽视却最致命的问题。断货意味着丢排名，冗余意味着现金流被套牢。

## 库存管理的三大目标

1. **不断货** — 保持Listing在售，维持排名
2. **不冗余** — 控制库存周转，释放现金流
3. **低成本** — 平衡头程、仓储和机会成本

## 安全库存公式

```
安全库存 = (日平均销量 × 最大补货天数) - (日平均销量 × 平均补货天数)
```

**实操简化版：**
```
备货数量 = 预计日销量 × (生产周期天 + 头程运输天 + 30天缓冲)
```

## 补货节奏规划

| 运输方式 | 头程时间 | 建议补货频率 | 适合产品 |
|---------|---------|------------|---------|
| 空运 | 5-10天 | 每周 | 高价值/轻小/紧急 |
| 海运快船 | 15-25天 | 每2周 | 大多数产品 |
| 海运普船 | 25-40天 | 每月 | 大件/低价值 |

## 避免库存冗余的方法

- **定期清库：** 每月Review库龄超过90天的SKU
- **促销去库存：** 用Coupon、Outlet等渠道清理慢动销品
- **停售止损：** 连续亏损且无回暖迹象的产品果断停止补货
- **移仓换标：** 账号出问题的库存可以转移到新账号
